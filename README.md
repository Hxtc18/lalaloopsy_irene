# 🎀 Lalaloopsy: El Terror de las Tijeras — PWA

## Cómo publicar en GitHub Pages (5 minutos)

### Paso 1 — Crear repositorio
1. Ve a [github.com](https://github.com) e inicia sesión
2. Haz clic en **"New repository"** (botón verde)
3. Nombre: `lalaloopsy` (o el que quieras)
4. Déjalo en **Public**
5. Haz clic en **"Create repository"**

### Paso 2 — Subir los archivos
En la página del repositorio vacío:
1. Haz clic en **"uploading an existing file"**
2. Arrastra y suelta **todos** estos archivos/carpetas:
   ```
   index.html
   manifest.json
   sw.js
   icons/
     icon-192.png
     icon-512.png
   ```
3. Escribe un mensaje como `"Subir juego"` abajo
4. Haz clic en **"Commit changes"**

### Paso 3 — Activar GitHub Pages
1. Ve a **Settings** (pestaña en tu repo)
2. En el menú izquierdo haz clic en **"Pages"**
3. En "Source" selecciona **"Deploy from a branch"**
4. Branch: **main**, carpeta: **/ (root)**
5. Haz clic en **"Save"**
6. Espera ~2 minutos y tu juego estará en:
   ```
   https://TU_USUARIO.github.io/lalaloopsy/
   ```

## Instalar en el teléfono (Android)
1. Abre el link en **Chrome**
2. Toca el menú ⋮ → **"Añadir a pantalla de inicio"**
3. ¡Listo! Aparece como una app y funciona sin internet

## Instalar en iPhone (iOS)
1. Abre el link en **Safari**
2. Toca el botón compartir □↑ → **"Añadir a pantalla de inicio"**
3. ¡Listo!
